# MOBAGPT

MOBAGPT is a League of Legends itemization recommendation system designed to suggest optimal builds based on champion matchups, team compositions, and in-game context.

The project aims to assist players with adaptive item recommendations using data-driven approaches and machine learning techniques.

---

## Features

- Champion-specific item recommendations
- Context-aware build suggestions
- Adaptive itemization against enemy team compositions
- Data collection and preprocessing pipeline
- Machine learning based recommendation logic
- Extensible architecture for future experimentation

---

## Tech Stack

- Python
- Riot API
- Machine Learning / Data Analysis
- Docker
- GitHub Actions
